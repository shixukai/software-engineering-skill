## 1. 判断问题

逻辑改写保持真值，也保持求值行为吗？

## 2. 条件与证据

适用：

- 权限、校验、分支、过滤条件或状态守卫变化
- 多个条件、否定或量词使需求有歧义

不适用或需调整：

- 无行为含义的纯文字改动

必要证据：

- 条件的领域含义与变量取值域
- 求值顺序、缺失值与副作用约定

## 3. 操作与取舍

1. 把复合条件拆成可命名的事实，写清且/或/非、包含边界以及所有/存在的量化范围；需求有空集合或未知值时明确其含义。
2. 用决策表、真值枚举或边界分组核对允许/拒绝情形；寻找条件矛盾、遗漏与重叠，不能用一个成功示例证明全部输入。
3. 化简或重排条件时同时核对短路、异常、访问安全及副作用；先保障前提再访问数据。纯布尔等价不能自动证明有副作用表达式可交换。
4. 将已确认的判定连接到前后置条件或状态不变量，再选能区分错误分支的测试；对一般性结论需要归纳/证明时记录假设与证明义务。

- 完整真值表随独立条件数增长；可按约束消去不可达组合但须保留依据
- 拆出命名条件提升可读性，也可能提前求值或捕获过期状态

## 4. 验证与反例

- 允许、拒绝与边界组合有可解释预期
- 逻辑等价与运行行为等价分别核对

反例：把分母非零的检查移到除法之后，真值形式看似等价却先触发错误；把“存在符合者”写成“全部符合”改变了空集行为。
