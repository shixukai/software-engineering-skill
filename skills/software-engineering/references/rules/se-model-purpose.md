## 1. 判断问题

这个模型保留了什么，省略了什么？

## 2. 条件与证据

适用：

- 接口、状态、依赖或业务规则难以仅凭文字核对

不适用或需调整：

- 图表不能帮助当前决定时无需建模

必要证据：

- 模型用途、边界、语义、假设与对应事实

## 3. 操作与取舍

1. 选择所需视图，标清实体、关系和约束；状态问题列合法/非法转换，结构问题核对职责和依赖。
2. 检查视图间一致性及与实现/需求的联系；证明或仿真结论只在模型假设内成立。

- 更多视图增加同步维护成本。

## 4. 验证与反例

- 用边界输入和反例检查模型，记录无法表达的风险。

反例：组件图没有环，不能证明运行时消息流没有反馈循环。
