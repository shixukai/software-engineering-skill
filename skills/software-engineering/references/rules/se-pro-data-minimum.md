## 1. 判断问题

为完成当前用途，究竟需要保留哪些数据？

## 2. 条件与证据

适用：

- 收集、组合、记录或共享个人/保密数据

不适用或需调整：

- 不把非敏感测试样本一概套用同等流程

必要证据：

- 用途、访问者、来源、保存和删除要求

## 3. 操作与取舍

1. 减少不必要字段与访问；说明保存、删除和用途变化处理。
2. 分析合并或日志中的再识别与意外泄露；专业伦理依据不替代适用法规核实。

- 可观测性与数据保护需共同设计。

## 4. 验证与反例

- 核对实际存储、日志、导出和清理行为是否符合约定。

反例：移除姓名但保留可关联标识，不能保证不可识别。
