## 1. 判断问题

输入合法时，中间运算、转换或舍入会越界吗？

## 2. 条件与证据

适用：

- 金额、计数、尺寸、时长、比率或数值比较
- 数值类型、单位、序列化或运算顺序改变

不适用或需调整：

- 没有数值语义变化的纯样式修改

必要证据：

- 数值含义、单位、有效范围与精度要求
- 目标语言/库的溢出、除法、转换和特殊值规则

## 3. 操作与取舍

1. 明确单位、量纲、最大/最小有效值、是否允许缺失，以及舍入发生在哪里；数值类型依据表示需求选择。
2. 从输入到结果逐个检查中间乘加、除法、索引和转换；目标类型足够宽不代表计算前的窄类型不会溢出，调整运算顺序也要重新检查精度与范围。
3. 精确十进制或离散计数优先评估对应表示与尺度，浮点测量则依据误差目标制定比较；不套用通用 epsilon，也不把所有浮点相等比较一概判错。
4. 核实除零、溢出/下溢、舍入、非有限值及序列化跨边界行为；用最小/最大、界内/界外、临界舍入和独立可核算输入验证。

- 更宽类型不能解决所有精度问题，十进制/大整数也有成本
- 改变求值次序可能缓解某种误差但扩大另一种误差，需要检查完整范围

## 4. 验证与反例

- 中间结果与最终结果均满足范围
- 误差与舍入策略能由业务要求解释，边界检查使用独立预期

反例：最终商能放进整数，乘法中间值却先溢出；货币改用浮点容差会让本应精确的账目差异被吞掉。
