## 1. 判断问题

下一项观测能排除哪种解释？

## 2. 条件与证据

适用：

- 缺陷原因不明或有多个合理解释
- 偶发错误需要缩小触发条件

不适用或需调整：

- 仅凭现象或近期改动就宣布根因
- 安全恢复须先进行，却仍执意等待完整复现

必要证据：

- 预期与实际行为
- 环境、版本、输入和复现条件
- 支持及反驳各假设的观测

## 3. 操作与取舍

1. 记录现象和边界，尽量稳定复现并缩小输入
2. 列出能解释现有数据的多个假设，保留矛盾数据
3. 为最有区分力的实验写下各假设预期结果，再执行一次受控变更或观察
4. 按结果排除或修正假设；用应失败和应成功的邻近条件验证解释

- 缩小用例有助定位，但可能移除竞争时序等关键条件
- 观测与工具也可能改变运行；不可复现时保留不确定性

## 4. 验证与反例

- 根因解释符合触发与不触发条件
- 失败实验也记入排除依据
- 证据不足时交付最强假设和下一项实验，不伪称确认

反例：发布后错误增多只能说明时间相关；若没有机制和对照证据，不能把最新提交直接当根因。
