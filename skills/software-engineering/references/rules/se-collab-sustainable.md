## 1. 判断问题

低产出的约束来自什么，改进是否转嫁了长期成本？

## 2. 条件与证据

适用：

- 计划长期依赖加班、频繁切换或关键人员过载
- 团队请求改善协作效率和可持续交付

不适用或需调整：

- 不能依据书籍给个人贴上低效、不投入或能力不足标签
- 不推导统一办公布局、固定专注时长或禁止远程协作
- 应急事件的短时集中投入需单独判断，不和长期常态混为一谈

必要证据：

- 工作类型、值守和即时响应需求
- 会议、打断、并行任务和交接负担
- 交付质量、返工、实际投入及人员稳定性的证据

## 3. 操作与取舍

1. 先区分需要深度连续工作的任务与需要即时响应的任务，识别可减少的会议、等待和上下文切换。
2. 在现有权限内提出有期限的改进实验，例如集中答疑、轮值承接中断、明确优先级、保护可约定的专注时间；保留必要协作和紧急通道。
3. 计划容量按可持续投入估算，长期赶工要计入返工、恢复、离职与知识流失风险；优先比较范围和依赖调整。
4. 用团队层面的交付与质量变化复核收益，征求受影响人员反馈；不用监控个人或强制统一工作方式替代分析。

- 保护专注有利于复杂工作，但过度隔离会延迟协作和求助
- 稳定团队与可持续节奏可能牺牲短期峰值，却减少隐性损耗；效果仍需当前环境验证

## 4. 验证与反例

- 改进针对观察到的工作障碍而非个人归因
- 同时观察交付、质量和协作可达性
- 没有把历史统计或作者经验升级为统一阈值

反例：把连续加班的产出除以标准工时，报告效率提高，却漏算真实投入、返工和关键人员离开后的替补成本。
